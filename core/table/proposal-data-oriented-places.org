* The idea
The anchor picks the seam. Three anchors, three seams, each one check on the hot path whose common
answer is "nothing":
- a path (a process, /dev): a trie of names on the root, part "process"; the walk reads it before
  children, *one tracked read per walk*
- a node, replacing what reads see (drag ghost, optimistic write, Basman override): patch nodes; an
  overlay library in front of places' =table= (the seam places already has); *one Map check per read*
- a node, asked for (cursors, who is here): part "presence" on the anchor; *no seam*, a plain read
- saved content: =children=, as today
- saving and sending: per side, per part, as data; never per kind of thing (*decided*: "something
  might be permanent on their side and ephemeral on mine")

Why the anchor decides: a path-anchored thing entered at the table read (by id) would show at every
path the folder is mounted at, against "a process lives at a _path_" (*decided*). A node-anchored
thing entered at the walk would vanish when the node is reached by another route. So path things
enter at the walk; node things enter at the read.

- per-path computers were union-check's cost (601 focuses, 1.1–1.3 s): a computer costs 6–8 µs to make,
  a walk 1–2 µs

* 6. Where it strains
- the walk's order (rows, then =children=; the ephemeral wins) is code in places, not data: "designable"
  waits on the in-graph description (*later*). the walk could read it once a walk from the root's
  attributes: one more spot
- the other-device check ("on another device the same, while the ephemeral channel says it's there") is
  not met by default: a walk reads only its own root's rows (put off). presence shows it; it doesn't
  walk it
- overlays apply to every reader on the device: no overlay for one process or one reader ("of a
  reader": *open*). a boxed process sees another process's drag ghost
- overlaid entries are made up in places' table seam: =who= must answer for them, and their commit
  carries a header the overlay library makes. a patch node is data; its overlaid entry is kept while
  it is active
- =at= as {time, actor} in whole seconds is weak until change identity (*open*); two changes in one
  second by one actor look alike
- renaming /work while clock runs: the row stays at [work, clock], unreachable until there is a /work
  again; the inspector shows it (by path, as a symlink breaks; plan.org's open item on overrides is the
  same shape)
- each start and stop rewrites one entry a root; its change shows only the latest (no log, *decided*)
- a reader of get(/work) is marked at every start and stop under /work (a deep spot at [work] in the
  rows); its equal result cuts it. ≤1/s
- the cache adds a second way places marks (walks again at commit); walks alone cost 1–2 µs. what it
  buys: one key a reader, the equal cut, watches by id
- presence has two shapes in one part (a node's rows; a folder's name → rows); a reader knows which
- a process in a folder that isn't there: refused at start (*mine*); a folder taken away later leaves an
  orphan row
- the plumber needs a kind on nodes and on needs and provides: an idea so far
