* The yardstick
What a design has to meet, from chee 10-12:
1. a read of an id can give several items: "ephemeral-pending, ephemeral, (pending,
   normal)[]...(per conflict)", many ephemeral heads; variants, rewind, protect's stand-ins the
   same kind
2. a node has value?, and attributes and children reachable by the same name
3. a node doesn't know subduction; op's patches are local, not a CRDT
4. a folder mounted in two places shows its children in both
5. writes to the persisted layer, reads from the ephemeral one, by default, but "i don't think
   this layer of the system should know about ephemeral or pending"
6. a handle is of the place; places pushed, not walked again
7. value, attributes and children are three things, changing separately
8. concurrent placements don't conflict as whole lists
